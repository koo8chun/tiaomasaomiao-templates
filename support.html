条码喵喵 — 帮助与支持

免费工具：单次/连续扫码、条码与二维码生成、简易盘点、CSV 导出。数据保存在本机。

常见问题

  • 扫码没有反应：请在系统设置中允许相机权限。
  • 无法保存码图：请允许相册权限。
  • 导出 CSV：使用系统分享保存到「文件」或发送到邮件。

问题反馈请提交 GitHub Issues（公开模板仓库）。

Barcode Miao — Support

A free tool for barcode/QR scanning, code generation, simple stocktake, and CSV export. Data stays on your device.

FAQ

  • Scan does nothing: allow Camera in iOS Settings.
  • Cannot save images: allow Photos access.
  • CSV export: use the system share sheet to save to Files or Mail.

Feedback: GitHub Issues on the public templates repo.
